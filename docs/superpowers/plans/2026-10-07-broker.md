# Broker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `apps/broker`, the single entry point that routes client requests to processors by variant name or alias, with a Postgres registry managed by a CLI, per-key access and rate limits, health checks, and usage summaries. First, extract the processor's generic HTTP and runtime plumbing into a shared `@dpp/server` package.

**Architecture:** Express 5 controllers → services (registry snapshot, health monitor, instance selector, proxy, usage stats) → (Drizzle registry repository, `fetch`-based processor client), wired with tsyringe exactly like `apps/processor`. The registry is loaded into an immutable in-memory snapshot and reloaded on a timer and on `SIGHUP`; requests never query the database. Calculation requests are forwarded as raw bytes; the processor stays the only validator of calculation bodies.

**Tech Stack:** Node.js 24, pnpm 12.9.1 workspace, TypeScript 7.0.2, tsdown 0.23, vitest 5, Express 5, express-rate-limit 8, cors 2, helmet 8, zod 4, tsyringe 4, Drizzle ORM 0.45 + drizzle-kit 0.31, node-postgres, PGlite (tests), supertest.

**Spec:** `docs/superpowers/specs/2026-10-07-broker-design.md` (read it alongside this plan). The processor's spec, `docs/superpowers/specs/2026-10-05-processor-design.md`, describes the code Task 1 extracts from.

## Review Focus

1. **An empty or garbage `X-Api-Key` header.** A client whose key variable is unset often sends `X-Api-Key:` with an empty value. That must be `401 UNAUTHORIZED`, not silently anonymous. Test in Task 11.
2. **An alias pointing at a private variant.** Anonymous callers must get `404 VARIANT_NOT_FOUND` through the alias too, and `GET /variants` must not list the private variant or its aliases. Test in Task 8 and Task 11.
3. **A processor that starts after the broker.** All instances are down at startup; once the processor is up, the next health check makes the variant available without restarting the broker. Test in Task 7.
4. **Registry reloads that change instances.** A removed instance's state disappears; a newly added instance starts `down` until checked, even if an instance with the same URL used to belong to another variant. Test in Task 7.
5. **Processor error responses are not broker failures.** A processor `500 CALCULATION_FAILED` or `503 OVERLOADED` passes through unchanged and does not mark the instance down or trigger a retry. Test in Task 9.

## Spec clarifications made while planning

- **`loadEnvironmentVariables` also moves to `@dpp/server`.** The broker needs it too.
- **`@dpp/server` has three entries:** `@dpp/server` (everything), `@dpp/server/errors` (the API errors only, safe for the processor's worker), and `@dpp/server/testing` (test helpers).
- **E2E helpers:** `freePort`, `startTestPostgres`, and `startProcess` move into `@dpp/server/testing`, and the processor's e2e test uses them. The broker's e2e test sends `/difficulty` with an uploaded `.osu` file (`{ beatmap: { file } }`), which the processor calculates without calling the beatmap service, so no stub beatmap service is needed. This resolves the spec's first "to verify" item.
- **A body over the limit returns `413`** with code `INVALID_REQUEST`, the status the shared error handler already passes through from body-parser (the processor behaves the same). The spec's table says 400; Task 11 updates the spec.
- **helmet's `Cross-Origin-Resource-Policy` is set to `cross-origin`**, so browsers on other origins can read responses.
- **The CLI applies migrations** before running a command, so it works before the broker has ever started.
- **Spec changes from the plan review (2026-10-09), already applied to the spec:** `ANON_RATE_LIMIT=0` turns anonymous access off (requests without a key get `401 UNAUTHORIZED` "An API key is required"); the `key_prefix` column is dropped and keys are identified by name only.
- **Timeouts use `setTimeout`, not `AbortSignal.timeout`.** Vitest's fake timers cannot advance `AbortSignal.timeout` (it uses Node's internal timers; checked), but they do drive an `AbortController` aborted from `setTimeout` while a real `fetch` is pending (checked). So timeout tests run on fake time instead of waiting.
- **Revoked keys are not loaded into the snapshot**; an unknown and a revoked key look the same to the broker (both 401).
- **Unknown processor routes under `/variants/:name/`** return `404 INVALID_REQUEST "Route not found"`, the same as any unknown route, before the variant is resolved.
- **Spec "to verify" items, checked while planning:** `express-rate-limit` 8.x declares `express >= 4.11` as its peer, accepts `limit` as `(req, res) => number | Promise<number>`, and exports `ipKeyGenerator(ip, ipv6Subnet?)`. `express.raw` uses the same body-parser error objects (`type: "entity.too.large"`, `status: 413`) that `errorHandler` maps. Express 5's `/:name/*route` gives `req.params.route` as an array of path segments, and Node's `fetch` accepts a `Buffer` body (both checked with TypeScript 7 in this repository).

```ts
import { Router, type RequestHandler } from "express";
import type { RouteDefinition } from "../decorators/routes";
import { getContainer } from "../dependencies/container";

type ControllerClass = new () => Record<string, RequestHandler>;

/**
 * Creates a router from the routes declared on controllers. Import the app's controllers before calling this, so
 * their decorators have registered them.
 */
export function createRouter(container = getContainer()): Router {
    const router = Router();

    // Reflect metadata is untyped; the @Controller and route decorators write these values.
    const controllers =
        (Reflect.getMetadata("controllers", globalThis) as
            ControllerClass[] | undefined) ?? [];

    for (const Controller of controllers) {
        const basePath = Reflect.getMetadata("basePath", Controller) as
            string | undefined;

        if (!basePath) {
            throw new Error(
                `Controller ${Controller.name} has no base path; decorate it with @Controller`,
            );
        }

        const routes =
            (Reflect.getMetadata("routes", Controller) as
                RouteDefinition[] | undefined) ?? [];

        if (!container.isRegistered(Controller)) {
            container.registerSingleton(Controller);
        }

        const instance = container.resolve(Controller);

        for (const route of routes) {
            const handler = instance[route.handlerName];

            if (!handler) {
                throw new Error(
                    `${Controller.name}.${route.handlerName} does not exist`,
                );
            }

            router[route.method](
                `${basePath}${route.path}`,
                handler.bind(instance),
            );
        }
    }

    return router;
}
```

Replace `packages/server/src/database/DatabaseConnection.ts` with:

```ts
import { drizzle, type NodePgDatabase } from "drizzle-orm/node-postgres";
import { migrate } from "drizzle-orm/node-postgres/migrator";
import { Pool } from "pg";

/**
 * Connection settings for a Postgres database.
 */
export interface DatabaseSettings {
    readonly host: string;
    readonly port: number;
    readonly name: string;
    readonly user: string;
    readonly password: string;
}

/**
 * A connection pool to a Postgres database with a Drizzle schema. Disposing closes the pool.
 */
export class DatabaseConnection<
    TSchema extends Record<string, unknown>,
> implements AsyncDisposable {
    private readonly pool: Pool;
    private readonly nodePgDb: NodePgDatabase<TSchema>;

    /**
     * @param settings The connection settings.
     * @param schema The Drizzle schema.
     * @param pool The pool to use. Only tests pass this, to reach the pool without a server; it defaults to a pool
     * built from `settings`.
     */
    constructor(
        settings: DatabaseSettings,
        schema: TSchema,
        pool = new Pool({
            host: settings.host,
            port: settings.port,
            database: settings.name,
            user: settings.user,
            password: settings.password,
        }),
    ) {
        this.pool = pool;

        // An error on an idle pooled client (server restart, idle timeout, network failure) is emitted on the pool.
        // Without a listener it would be an uncaught exception; the pool discards the client and reconnects on demand.
        this.pool.on("error", (error) => {
            console.error("Idle database client failed:", error.message);
        });

        this.nodePgDb = drizzle(this.pool, { schema, casing: "snake_case" });
    }

    /**
     * The database, for repositories.
     */
    get db(): NodePgDatabase<TSchema> {
        return this.nodePgDb;
    }

    /**
     * Applies pending migrations from `migrationsFolder`.
     */
    async migrate(migrationsFolder: string): Promise<void> {
        await migrate(this.nodePgDb, { migrationsFolder });
    }

    [Symbol.asyncDispose](): Promise<void> {
        return this.pool.end();
    }
}
```

```ts
import type { DependencyContainer, InjectionToken } from "tsyringe";
import type { constructor } from "tsyringe/dist/typings/types";

/**
 * Registers every `@Injectable` class that has been loaded as a singleton under its token. Import the app's
 * injectable classes before calling this, so their decorators have run.
 */
export function registerInjectables(container: DependencyContainer): void {
    // Reflect metadata is untyped; `Injectable` writes these values.
    const classes =
        (Reflect.getMetadata("classes", globalThis) as
            constructor<unknown>[] | undefined) ?? [];

    for (const cls of classes) {
        const token = Reflect.getMetadata("registrationToken", cls) as
            InjectionToken<unknown> | undefined;

        if (!token) {
            throw new Error(
                `Class ${cls.name} has no registration token; decorate it with @Injectable`,
            );
        }

        container.registerSingleton(token, cls);
    }
}
```

```ts
import { spawn, type ChildProcess } from "node:child_process";
import { setTimeout as sleep } from "node:timers/promises";

/**
 * A running Node process started by {@link startProcess}. Disposing kills it if it is still running.
 */
export interface StartedProcess extends AsyncDisposable {
    readonly child: ChildProcess;

    /**
     * Resolves with the exit code when the process exits.
     */
    readonly exited: Promise<number | null>;

    /**
     * Everything the process has written to stdout and stderr so far.
     */
    output(): string;
}

/**
 * Starts `node <script>` and resolves once `GET readyUrl` answers with a 2xx status.
 *
 * @throws {Error} With the process output, if the process exits or `timeoutMs` passes before it is ready.
 */
export async function startProcess(options: {
    script: string;
    env: NodeJS.ProcessEnv;
    readyUrl: string;
    timeoutMs?: number;
}): Promise<StartedProcess> {
    const { script, env, readyUrl, timeoutMs = 20_000 } = options;
    const child = spawn("node", [script], { env });
    let output = "";

    child.stdout.on("data", (chunk: Buffer) => (output += chunk.toString()));
    child.stderr.on("data", (chunk: Buffer) => (output += chunk.toString()));

    const exited = new Promise<number | null>((resolve) =>
        child.once("exit", (code) => resolve(code)),
    );

    const started: StartedProcess = {
        child,
        exited,
        output: () => output,
        [Symbol.asyncDispose]: async () => {
            if (child.exitCode === null && child.signalCode === null) {
                child.kill("SIGKILL");
                await exited;
            }
        },
    };

    const deadline = Date.now() + timeoutMs;

    while (child.exitCode === null && child.signalCode === null) {
        const ready = await fetch(readyUrl)
            .then((response) => response.ok)
            .catch(() => false);

        if (ready) {
            return started;
        }

        if (Date.now() > deadline) {
            await started[Symbol.asyncDispose]();

            throw new Error(
                `${script} was not ready within ${timeoutMs.toString()} ms:\n${output}`,
            );
        }

        await sleep(200);
    }

    // Let the exit finish so the stream handlers have collected the last output.
    await exited;

    throw new Error(`${script} exited before it was ready:\n${output}`);
}
```

```ts
import { EnvironmentVariableKey as Key } from "@/types/env";
import type { DatabaseSettings } from "@dpp/server";
import { z } from "zod";

/**
 * A value for Express's `trust proxy` setting: `true`, `false`, a hop count, or addresses and subnets.
 */
export type TrustProxySetting = boolean | number | string;

/**
 * Deployment settings, read from environment variables.
 */
export interface Config {
    readonly port: number;
    readonly database: DatabaseSettings;
    readonly processor: {
        /**
         * Sent to every processor in `X-Api-Key`; each processor's `API_KEY`.
         */
        readonly apiKey: string;
        readonly timeoutSeconds: number;
    };
    readonly healthCheck: {
        readonly intervalSeconds: number;
        readonly timeoutSeconds: number;
    };
    readonly registryReloadIntervalSeconds: number;

    /**
     * Requests per minute per IP for callers without a key. 0 refuses requests without a key.
     */
    readonly anonymousRateLimit: number;
    readonly trustProxy: TrustProxySetting;

    /**
     * 0 disables usage summaries.
     */
    readonly usageSummaryIntervalSeconds: number;
}

/**
 * Thrown when environment variables are missing or invalid. The message names every invalid variable but never
 * includes values.
 */
export class ConfigError extends Error {
    constructor(message: string) {
        super(message);
        this.name = "ConfigError";
    }
}

const port = z.coerce.number().int().min(1).max(65535);
const seconds = z.coerce.number().int().min(1);

const databaseShape = {
    [Key.DatabaseHost]: z.string().min(1),
    [Key.DatabasePort]: port.default(5432),
    [Key.DatabaseName]: z.string().min(1),
    [Key.DatabaseUser]: z.string().min(1),
    [Key.DatabasePassword]: z.string().default(""),
};

const databaseSchema = z.object(databaseShape);

const schema = z.object({
    ...databaseShape,
    [Key.Port]: port,
    [Key.ProcessorApiKey]: z.string().min(16, "must be at least 16 characters"),
    [Key.ProcessorTimeoutSeconds]: seconds.default(30),
    [Key.HealthCheckIntervalSeconds]: seconds.default(10),
    [Key.HealthCheckTimeoutSeconds]: seconds.default(3),
    [Key.RegistryReloadIntervalSeconds]: seconds.default(30),
    [Key.AnonymousRateLimit]: z.coerce.number().int().min(0).default(30),
    [Key.TrustProxy]: z.string().default("false").transform(parseTrustProxy),
    [Key.UsageSummaryIntervalSeconds]: z.coerce
        .number()
        .int()
        .min(0)
        .default(300),
});

function parseTrustProxy(value: string): TrustProxySetting {
    if (value === "true") {
        return true;
    }

    if (value === "false") {
        return false;
    }

    return /^\d+$/.test(value) ? Number(value) : value;
}

function parse<T extends z.ZodType>(
    target: T,
    env: NodeJS.ProcessEnv,
): z.infer<T> {
    // An empty variable (`PORT=`) counts as unset, instead of being coerced to 0.
    const present = Object.fromEntries(
        Object.entries(env).filter(([, value]) => value !== ""),
    );
    const result = target.safeParse(present);

    if (!result.success) {
        const problems = result.error.issues.map(
            (issue) => `${issue.path.join(".")}: ${issue.message}`,
        );

        throw new ConfigError(
            `Invalid configuration:\n  ${problems.join("\n  ")}`,
        );
    }

    return result.data;
}

function toDatabaseSettings(
    values: z.infer<typeof databaseSchema>,
): DatabaseSettings {
    return {
        host: values[Key.DatabaseHost],
        port: values[Key.DatabasePort],
        name: values[Key.DatabaseName],
        user: values[Key.DatabaseUser],
        password: values[Key.DatabasePassword],
    };
}

/**
 * Reads and validates the broker's configuration.
 *
 * @throws {ConfigError} If any variable is missing or invalid.
 */
export function loadConfig(env: NodeJS.ProcessEnv): Config {
    const values = parse(schema, env);

    return {
        port: values[Key.Port],
        database: toDatabaseSettings(values),
        processor: {
            apiKey: values[Key.ProcessorApiKey],
            timeoutSeconds: values[Key.ProcessorTimeoutSeconds],
        },
        healthCheck: {
            intervalSeconds: values[Key.HealthCheckIntervalSeconds],
            timeoutSeconds: values[Key.HealthCheckTimeoutSeconds],
        },
        registryReloadIntervalSeconds:
            values[Key.RegistryReloadIntervalSeconds],
        anonymousRateLimit: values[Key.AnonymousRateLimit],
        trustProxy: values[Key.TrustProxy],
        usageSummaryIntervalSeconds: values[Key.UsageSummaryIntervalSeconds],
    };
}

/**
```

```ts
import type {
    ApiKeyRecord,
    Caller,
    Instance,
    RegistrySnapshot,
    Variant,
} from "./types";

/**
 * The registry tables as plain rows. Keys are only the ones to load (not revoked).
 */
export interface SnapshotRows {
    readonly variants: readonly {
        readonly name: string;
        readonly public: boolean;
        readonly description: string | null;
    }[];
    readonly instances: readonly Instance[];
    readonly aliases: readonly {
        readonly name: string;
        readonly variantName: string;
    }[];
    readonly keys: readonly {
        readonly id: number;
        readonly name: string;
        readonly keyHash: string;
        readonly rateLimitPerMinute: number | null;
        readonly allVariants: boolean;
    }[];
    readonly grants: readonly {
        readonly keyId: number;
        readonly variantName: string;
    }[];
}

const byString = (a: string, b: string) => (a < b ? -1 : a > b ? 1 : 0);

/**
 * Builds an immutable snapshot from registry rows.
 */
export function buildSnapshot(rows: SnapshotRows): RegistrySnapshot {
    const variants = new Map<string, Variant>();

    for (const row of [...rows.variants].sort((a, b) =>
        byString(a.name, b.name),
    )) {
        variants.set(row.name, {
            name: row.name,
            public: row.public,
            description: row.description,
            instances: rows.instances
                .filter((instance) => instance.variantName === row.name)
                .map(({ variantName, url }) => ({ variantName, url }))
                .sort((a, b) => byString(a.url, b.url)),
            aliases: rows.aliases
                .filter((alias) => alias.variantName === row.name)
                .map((alias) => alias.name)
                .sort(byString),
        });
    }

    const keysByHash = new Map<string, ApiKeyRecord>();

    for (const key of rows.keys) {
        keysByHash.set(key.keyHash, {
            id: key.id,
            name: key.name,
            rateLimitPerMinute: key.rateLimitPerMinute,
            allVariants: key.allVariants,
            grants: new Set(
                rows.grants
                    .filter((grant) => grant.keyId === key.id)
                    .map((grant) => grant.variantName),
            ),
        });
    }

    return {
        variants,
        aliases: new Map(
            rows.aliases.map((alias) => [alias.name, alias.variantName]),
        ),
        keysByHash,
    };
}

/**
 * The snapshot before the registry is first loaded.
 */
export const emptySnapshot: RegistrySnapshot = buildSnapshot({
    variants: [],
    instances: [],
    aliases: [],
    keys: [],
    grants: [],
});

/**
 * Identifies an instance across snapshots. The same URL under another variant is another instance.
 */
export function instanceKey(instance: Instance): string {
    return `${instance.variantName} ${instance.url}`;
}

export const anonymousCaller: Caller = { kind: "anonymous" };

/**
 * The caller's name for logs: the key's name, or `anonymous`.
 */
export function callerName(caller: Caller): string {
    return caller.kind === "key" ? caller.key.name : "anonymous";
}
```

```ts
            readonly rateLimitPerMinute?: number | null;

            .update(apiKeysTable)
            .set(changes)
            .where(eq(apiKeysTable.name, name));

        const [key] = await this.db
            .select({ id: apiKeysTable.id })
            .from(apiKeysTable)
            .where(eq(apiKeysTable.name, keyName));

            return false;

            .delete(apiKeyVariantsTable)

                and(
                    eq(apiKeyVariantsTable.variantName, variantName),
                    inArray(
                        apiKeyVariantsTable.keyId,
                        this.db
                            .select({ id: apiKeysTable.id })
                            .from(apiKeysTable)
                            .where(eq(apiKeysTable.name, keyName)),
                    ),
                ),
            )
            .returning({ keyId: apiKeyVariantsTable.keyId });

        return deleted.length > 0;

        const revoked = await this.db
            .update(apiKeysTable)
            .set({ revokedAt: new Date() })
            .where(
                and(
                    eq(apiKeysTable.name, name),
                    isNull(apiKeysTable.revokedAt),
                ),
            )
            .returning({ id: apiKeysTable.id });

        return revoked.length > 0;
    }

        const keys = await this.db
            .select()
            .from(apiKeysTable)
            .where(name === undefined ? undefined : eq(apiKeysTable.name, name))

        if (keys.length === 0) {
            return [];
        }

            .select()
            .from(apiKeyVariantsTable)
            .where(
                inArray(
                    apiKeyVariantsTable.keyId,
                    keys.map((key) => key.id),
                ),
            )
            .orderBy(asc(apiKeyVariantsTable.variantName));

        return keys.map((key) => ({
            name: key.name,
            rateLimitPerMinute: key.rateLimitPerMinute,
            allVariants: key.allVariants,
            grants: grants
                .filter((grant) => grant.keyId === key.id)
                .map((grant) => grant.variantName),
            createdAt: key.createdAt,
            revokedAt: key.revokedAt,
        }));
    }
}
```

```ts
import { createServer, type RequestListener } from "node:http";

/**
 * A plain HTTP server on 127.0.0.1 for a test. Disposing closes it, including connections still waiting for a
 * response.
 */
export interface TestHttpServer extends AsyncDisposable {
    /**
     * Base URL without a trailing slash.
     */
    readonly url: string;
}

export function startHttpServer(
    handler: RequestListener,
): Promise<TestHttpServer> {
    const server = createServer(handler);

    return new Promise((resolve, reject) => {
        server.listen(0, "127.0.0.1", () => {
            const address = server.address();

            if (!address || typeof address === "string") {
                reject(new Error("Server has no TCP address"));
                return;
            }

            resolve({
                url: `http://127.0.0.1:${address.port.toString()}`,
                [Symbol.asyncDispose]: () =>
                    new Promise<void>((done) => {
                        server.closeAllConnections();
                        server.close(() => done());
                    }),
            });
        });
    });
}
```

```ts
/**
 * An abort signal with a deadline. Disposing clears the timer.
 */
export interface Timeout extends Disposable {
    readonly signal: AbortSignal;
}

/**
 * Like `AbortSignal.timeout`, but built on `setTimeout`, so tests can advance it with fake timers (vitest cannot
 * fake `AbortSignal.timeout`, which uses Node's internal timers). The signal aborts with a `TimeoutError`
 * `DOMException`, as `AbortSignal.timeout` does.
 */
export function createTimeout(ms: number): Timeout {
    const controller = new AbortController();
    const timer = setTimeout(() => {
        controller.abort(
            new DOMException("The operation timed out", "TimeoutError"),
        );
    }, ms);

    return {
        signal: controller.signal,
        [Symbol.dispose]: () => clearTimeout(timer),
    };
}
```

```ts
import type { CalculatorAlgorithm, InfoResponse } from "@dpp/shared";
import { Modes } from "@rian8337/osu-base";
import { z } from "zod";
import type { InfoResult } from "./IProcessorClient";
import { createTimeout } from "./timeout";

const algorithms = [
    "live",
    "rebalance",
] as const satisfies readonly CalculatorAlgorithm[];

const infoSchema = z.object({
    id: z.string(),
    mode: z.enum(Modes),
    algorithm: z.enum(algorithms),
    calculatorVersion: z.string(),
    builtAt: z.string(),
}) satisfies z.ZodType<InfoResponse>;

/**
 * Whether `fetch` failed because a {@link createTimeout} signal fired.
 */
export function isTimeout(error: unknown): boolean {
    return error instanceof DOMException && error.name === "TimeoutError";
}

/**
 * A short reason for a failed `fetch`, preferring the network error's message (e.g. `connect ECONNREFUSED …`)
 * over fetch's generic "fetch failed".
 */
export function describeFetchError(error: unknown): string {
    if (isTimeout(error)) {
        return "timed out";
    }

    if (error instanceof Error) {
        return error.cause instanceof Error
            ? error.cause.message
            : error.message;
    }

    return String(error);
}

/**
 * Calls a processor's public `GET /info`.
 */
export async function fetchInfo(
    baseUrl: string,
    timeoutMs: number,
): Promise<InfoResult> {
    // Covers reading the body too, so it is disposed when the function returns.
    using timeout = createTimeout(timeoutMs);
    let response: Response;

    try {
        response = await fetch(`${baseUrl}/info`, { signal: timeout.signal });
    } catch (e) {
        return { kind: "failed", reason: describeFetchError(e) };
    }

    if (!response.ok) {
        await response.body?.cancel();

        return {
            kind: "failed",
            reason: `GET /info returned ${response.status.toString()}`,
        };
    }

    let body: unknown;

    try {
        body = await response.json();
    } catch (e) {
        return { kind: "failed", reason: describeFetchError(e) };
    }

    const parsed = infoSchema.safeParse(body);

    return parsed.success
        ? { kind: "ok", info: parsed.data }
        : { kind: "failed", reason: "GET /info returned an unexpected body" };
}
```

```ts
import { describeFetchError, fetchInfo, isTimeout } from "./fetchInfo";
import type {
    ForwardResult,
    InfoResult,
    IProcessorClient,
} from "./IProcessorClient";
import { createTimeout } from "./timeout";

@Injectable(dependencyTokens.processorClient)
export class ProcessorClient implements IProcessorClient {
    constructor(
        @inject(dependencyTokens.config)
        private readonly config: Config,
    ) {}

    getInfo(baseUrl: string, timeoutMs: number): Promise<InfoResult> {
        return fetchInfo(baseUrl, timeoutMs);
    }

    async forward(
        baseUrl: string,
        route: ProcessorRoute,
        body: Buffer,
        timeoutMs: number,
    ): Promise<ForwardResult> {
        // One signal for the whole exchange, so a slow body counts against the same timeout.
        using timeout = createTimeout(timeoutMs);
        let response: Response;

        try {
            response = await fetch(`${baseUrl}${route}`, {
                method: "POST",
                headers: {
                    "Content-Type": "application/json",
                    "X-Api-Key": this.config.processor.apiKey,
                },
                body,
                signal: timeout.signal,
            });
        } catch (e) {
            return isTimeout(e)
                ? { kind: "timeout" }
                : { kind: "connection-failed", reason: describeFetchError(e) };
        }

        try {
            return {
                kind: "response",
                status: response.status,
                contentType: response.headers.get("content-type"),
                body: Buffer.from(await response.arrayBuffer()),
            };
        } catch (e) {
            return isTimeout(e)
                ? { kind: "timeout" }
                : { kind: "broken", reason: describeFetchError(e) };
        }
    }
}
```

```ts
import type { IProcessorClient } from "@/clients/IProcessorClient";
import type { Instance } from "@/registry/types";
import type { InfoResponse } from "@dpp/shared";

/**
 * The result of one `GET /info` check of an instance.
 */
export type Probe =
    | { readonly state: "healthy"; readonly info: InfoResponse }
    | { readonly state: "mismatch"; readonly info: InfoResponse }
    | { readonly state: "down"; readonly reason: string };

export type InstanceState = Probe["state"];

/**
 * Checks an instance: healthy if its `/info` names the instance's variant, mismatch if it names another, down if
 * the call failed.
 */
export async function probeInstance(
    client: Pick<IProcessorClient, "getInfo">,
    instance: Instance,
    timeoutMs: number,
): Promise<Probe> {
    const result = await client.getInfo(instance.url, timeoutMs);

    if (result.kind === "failed") {
        return { state: "down", reason: result.reason };
    }

    return result.info.id === instance.variantName
        ? { state: "healthy", info: result.info }
        : { state: "mismatch", info: result.info };
}
```

```ts
import type { IProcessorClient } from "@/clients/IProcessorClient";
import type { Config } from "@/config/config";
import { dependencyTokens } from "@/dependencies/tokens";
import { instanceKey } from "@/registry/snapshot";
import type { Instance, RegistrySnapshot } from "@/registry/types";
import { Injectable } from "@dpp/server";
import type { InfoResponse } from "@dpp/shared";
import { inject } from "tsyringe";
import type { IHealthMonitor } from "./IHealthMonitor";
import { probeInstance, type InstanceState } from "./probe";

@Injectable(dependencyTokens.healthMonitor)
export class HealthMonitor implements IHealthMonitor {
    private instances: readonly Instance[] = [];
    private current = new Set<string>();
    private readonly states = new Map<string, InstanceState>();
    private readonly lastInfoByVariant = new Map<string, InfoResponse>();
    private round: Promise<void> | undefined;

    constructor(
        @inject(dependencyTokens.processorClient)
        private readonly client: IProcessorClient,
        @inject(dependencyTokens.config)
        private readonly config: Config,
    ) {}

    sync(snapshot: RegistrySnapshot): void {
        this.instances = [...snapshot.variants.values()].flatMap(
            (variant) => variant.instances,
        );
        this.current = new Set(this.instances.map(instanceKey));

        for (const key of this.states.keys()) {
            if (!this.current.has(key)) {
                this.states.delete(key);
            }
        }

        for (const name of this.lastInfoByVariant.keys()) {
            if (!snapshot.variants.has(name)) {
                this.lastInfoByVariant.delete(name);
            }
        }
    }

    checkAll(): Promise<void> {
        this.round ??= Promise.all(
            this.instances.map((instance) => this.check(instance)),
        )
            .then(() => undefined)
            .catch((e: unknown) => {
                console.error("Health check round failed:", e);
            })
            .finally(() => {
                this.round = undefined;
            });

        return this.round;
    }

    start(): Disposable {
        const timer = setInterval(() => {
            void this.checkAll();
        }, this.config.healthCheck.intervalSeconds * 1000);

        timer.unref();

        return { [Symbol.dispose]: () => clearInterval(timer) };
    }

    stateOf(instance: Instance): InstanceState {
        return this.states.get(instanceKey(instance)) ?? "down";
    }

    isHealthy(instance: Instance): boolean {
        return this.stateOf(instance) === "healthy";
    }

    markDown(instance: Instance, reason: string): void {
        this.setState(instance, "down", reason);
    }

    lastInfo(variantName: string): InfoResponse | undefined {
        return this.lastInfoByVariant.get(variantName);
    }

    private async check(instance: Instance): Promise<void> {
        const probe = await probeInstance(
            this.client,
            instance,
            this.config.healthCheck.timeoutSeconds * 1000,
        );

        switch (probe.state) {
            case "healthy":
                this.setState(instance, "healthy");

                if (this.current.has(instanceKey(instance))) {
                    this.lastInfoByVariant.set(
                        instance.variantName,
                        probe.info,
                    );
                }
                break;
            case "mismatch":
                this.setState(
                    instance,
                    "mismatch",
                    `reports variant "${probe.info.id}"`,
                );
                break;
            case "down":
                this.setState(instance, "down", probe.reason);
                break;
        }
    }

    private setState(
        instance: Instance,
        state: InstanceState,
        detail?: string,
    ): void {
        const key = instanceKey(instance);

        // The instance was removed by a registry reload while it was being checked or forwarded to.
        if (!this.current.has(key)) {
            return;
        }

        const previous = this.states.get(key);

        this.states.set(key, state);

        if (previous === state) {
            return;
        }

        const message = `Instance ${instance.url} of ${instance.variantName}: ${previous ?? "unchecked"} → ${state}${detail ? ` (${detail})` : ""}`;

        if (state === "healthy") {
            console.log(message);
        } else if (state === "down") {
            console.warn(message);
        } else {
            console.error(message);
        }
    }
}
```

```ts
    private snapshot: RegistrySnapshot = emptySnapshot;

    constructor(
        @inject(dependencyTokens.registryRepository)
        private readonly repository: Pick<IRegistryRepository, "loadSnapshot">,

        this.snapshot = snapshot;
        this.health.sync(snapshot);
    }

        try {
            await this.load();

            return true;
        } catch (e) {

                e instanceof Error ? e.message : e,
            );

        const timer = setInterval(() => {
            void this.reload();
        }, this.config.registryReloadIntervalSeconds * 1000);

        timer.unref();

        return { [Symbol.dispose]: () => clearInterval(timer) };

        // The map lookup compares hashes, not keys, so its timing reveals nothing usable about stored keys.
        return this.snapshot.keysByHash.get(hashApiKey(rawKey));
    }

    resolve(name: string, caller: Caller): Variant | undefined {
        const variant =
            this.snapshot.variants.get(name) ??
            this.snapshot.variants.get(this.snapshot.aliases.get(name) ?? "");

        return variant && this.canUse(variant, caller) ? variant : undefined;
    }

    visibleVariants(caller: Caller): Variant[] {
        return [...this.snapshot.variants.values()].filter((variant) =>
            this.canUse(variant, caller),
        );
    }

    summary(): string {
        const variants = [...this.snapshot.variants.values()];
        const instances = variants.reduce(
            (count, variant) => count + variant.instances.length,
            0,
        );

        return `${variants.length.toString()} variants, ${instances.toString()} instances, ${this.snapshot.aliases.size.toString()} aliases, ${this.snapshot.keysByHash.size.toString()} keys`;
    }

    private canUse(variant: Variant, caller: Caller): boolean {
        return (
            variant.public ||
            (caller.kind === "key" &&
                (caller.key.allVariants || caller.key.grants.has(variant.name)))
```

```ts
import { instanceKey } from "@/registry/snapshot";
import type { Instance, Variant } from "@/registry/types";
import { Injectable } from "@dpp/server";
import { inject } from "tsyringe";
import type { IHealthMonitor } from "./IHealthMonitor";
import type { IInstanceSelector } from "./IInstanceSelector";

@Injectable(dependencyTokens.instanceSelector)
export class InstanceSelector implements IInstanceSelector {
    private readonly counters = new Map<string, number>();

    constructor(
        @inject(dependencyTokens.healthMonitor)
        private readonly health: Pick<IHealthMonitor, "isHealthy">,
    ) {}

    select(variant: Variant, ...exclude: Instance[]): Instance | undefined {
        const excluded = new Set(exclude.map(instanceKey));
        const candidates = variant.instances.filter(
            (instance) =>
                this.health.isHealthy(instance) &&
                !excluded.has(instanceKey(instance)),
        );

        if (candidates.length === 0) {
            return undefined;
        }

        const counter = this.counters.get(variant.name) ?? 0;

        this.counters.set(variant.name, counter + 1);

        return candidates[counter % candidates.length];
    }
}
```

```ts
import type {
    ForwardResult,
    IProcessorClient,
} from "@/clients/IProcessorClient";
import type { Config } from "@/config/config";
import { dependencyTokens } from "@/dependencies/tokens";
import type { Instance, Variant } from "@/registry/types";
import {
    ProcessorError,
    ProcessorTimeoutError,
    VariantUnavailableError,
} from "@/types/errors";
import { Injectable } from "@dpp/server";
import type { ProcessorRoute } from "@dpp/shared";
import { inject } from "tsyringe";
import type { IHealthMonitor } from "./IHealthMonitor";
import type { IInstanceSelector } from "./IInstanceSelector";
import type { IProxyService, ProxyResponse } from "./IProxyService";

type Answered = Exclude<ForwardResult, { kind: "connection-failed" }>;

@Injectable(dependencyTokens.proxyService)
export class ProxyService implements IProxyService {
    constructor(
        @inject(dependencyTokens.processorClient)
        private readonly client: IProcessorClient,
        @inject(dependencyTokens.instanceSelector)
        private readonly selector: IInstanceSelector,
        @inject(dependencyTokens.healthMonitor)
        private readonly health: Pick<IHealthMonitor, "markDown">,
        @inject(dependencyTokens.config)
        private readonly config: Config,
    ) {}

    async forward(
        variant: Variant,
        route: ProcessorRoute,
        body: Buffer,
    ): Promise<ProxyResponse> {
        const first = this.selector.select(variant);

        if (!first) {
            throw new VariantUnavailableError(variant.name);
        }

        const result = await this.send(first, route, body);

        if (result.kind !== "connection-failed") {
            return this.toResponse(variant, first, result);
        }

        // Nothing reached the processor, and calculations are pure, so another instance can safely take it.
        this.health.markDown(first, result.reason);

        const second = this.selector.select(variant, first);

        if (!second) {
            throw this.unreachable(variant);
        }

        const retried = await this.send(second, route, body);

        if (retried.kind === "connection-failed") {
            this.health.markDown(second, retried.reason);

            throw this.unreachable(variant);
        }

        return this.toResponse(variant, second, retried);
    }

    private send(
        instance: Instance,
        route: ProcessorRoute,
        body: Buffer,
    ): Promise<ForwardResult> {
        return this.client.forward(
            instance.url,
            route,
            body,
            this.config.processor.timeoutSeconds * 1000,
        );
    }

    private toResponse(
        variant: Variant,
        instance: Instance,
        result: Answered,
    ): ProxyResponse {
        const source = `Processor at ${instance.url} (${variant.name})`;

        switch (result.kind) {
            case "timeout":
                throw new ProcessorTimeoutError(variant.name);
            case "broken":
                console.error(
                    `${source} broke off its response: ${result.reason}`,
                );

                throw new ProcessorError(
                    `The processor for variant "${variant.name}" failed while responding`,
                );
            case "response":
                if (result.status === 401) {
                    console.error(
                        `${source} rejected the broker's key; check that PROCESSOR_API_KEY matches its API_KEY`,
                    );

                    throw new ProcessorError(
                        `The processor for variant "${variant.name}" rejected the broker`,
                    );
                }

                if (!result.contentType?.startsWith("application/json")) {
                    console.error(
                        `${source} returned a non-JSON response with status ${result.status.toString()}`,
                    );

                    throw new ProcessorError(
                        `The processor for variant "${variant.name}" returned an invalid response`,
                    );
                }

                return { status: result.status, body: result.body };
        }
    }

    private unreachable(variant: Variant): ProcessorError {
        return new ProcessorError(
            `Could not connect to a processor for variant "${variant.name}"`,
        );
    }
}
```

```ts
import type { Config } from "@/config/config";
import { dependencyTokens } from "@/dependencies/tokens";
import { Injectable } from "@dpp/server";
import { inject } from "tsyringe";
import type { IUsageStats, RequestRecord } from "./IUsageStats";

interface VariantUsage {
    readonly durations: number[];
    /** Status class (`2xx`) → count. */
    readonly statuses: Map<string, number>;
}

interface CallerUsage {
    requests: number;
    rateLimited: number;
}

/**
 * The nearest-rank percentile of sorted values.
 */
function percentile(sorted: readonly number[], p: number): number {
    return sorted[Math.max(0, Math.ceil((p / 100) * sorted.length) - 1)] ?? 0;
}

const byName = <T>([a]: [string, T], [b]: [string, T]) =>
    a < b ? -1 : a > b ? 1 : 0;

@Injectable(dependencyTokens.usageStats)
export class UsageStats implements IUsageStats {
    private variants = new Map<string, VariantUsage>();
    private callers = new Map<string, CallerUsage>();
    private since = Date.now();

    constructor(
        @inject(dependencyTokens.config)
        private readonly config: Config,
    ) {}

    record(request: RequestRecord): void {
        this.callerUsage(request.caller).requests++;

        if (request.variant === null) {
            return;
        }

        let usage = this.variants.get(request.variant);

        if (!usage) {
            usage = { durations: [], statuses: new Map() };
            this.variants.set(request.variant, usage);
        }

        const statusClass = `${Math.floor(request.status / 100).toString()}xx`;

        usage.durations.push(Math.round(request.durationMs));
        usage.statuses.set(
            statusClass,
            (usage.statuses.get(statusClass) ?? 0) + 1,
        );
    }

    recordRateLimited(caller: string): void {
        this.callerUsage(caller).rateLimited++;
    }

    takeSummary(): string[] {
        const now = Date.now();
        const prefix = `Usage over ${Math.round((now - this.since) / 1000).toString()} s:`;
        const lines: string[] = [];

        for (const [name, usage] of [...this.variants].sort(byName)) {
            const sorted = [...usage.durations].sort((a, b) => a - b);
            const statuses = [...usage.statuses]
                .sort(byName)
                .map(
                    ([statusClass, count]) =>
                        `${statusClass} ${count.toString()}`,
                )
                .join(", ");

            lines.push(
                `${prefix} variant ${name}: ${sorted.length.toString()} requests (${statuses}), p50 ${percentile(sorted, 50).toString()} ms, p95 ${percentile(sorted, 95).toString()} ms`,
            );
        }

        for (const [name, usage] of [...this.callers].sort(byName)) {
            lines.push(
                `${prefix} caller ${name}: ${usage.requests.toString()} requests, ${usage.rateLimited.toString()} rate-limited`,
            );
        }

        this.variants = new Map();
        this.callers = new Map();
        this.since = now;

        return lines;
    }

    start(): Disposable {
        const intervalSeconds = this.config.usageSummaryIntervalSeconds;

        if (intervalSeconds === 0) {
            return { [Symbol.dispose]: () => undefined };
        }

        const timer = setInterval(() => {
            this.logSummary();
        }, intervalSeconds * 1000);

        timer.unref();

        return {
            [Symbol.dispose]: () => {
                clearInterval(timer);
                this.logSummary();
            },
        };
    }

    private logSummary(): void {
        for (const line of this.takeSummary()) {
            console.log(line);
        }
    }

    private callerUsage(caller: string): CallerUsage {
        let usage = this.callers.get(caller);

        if (!usage) {
            usage = { requests: 0, rateLimited: 0 };
            this.callers.set(caller, usage);
        }

        return usage;
    }
}
```

```ts
import { createServer } from "node:http";

export interface StubRequest {
    readonly path: string;
    readonly apiKey: string | undefined;
    readonly contentType: string | undefined;
    readonly body: string;
}

export interface StubReply {
    readonly status: number;
    readonly body: unknown;
}

/**
 * A stand-in for a processor: answers `GET /info` for its variant id and records calculation requests.
 */
export interface StubProcessor extends AsyncDisposable {
    readonly url: string;
    readonly requests: StubRequest[];
    reply(handler: (request: StubRequest) => StubReply): void;
    close(): Promise<void>;
}

export function startStubProcessor(id: string): Promise<StubProcessor> {
    const requests: StubRequest[] = [];
    let handler = (request: StubRequest): StubReply => ({
        status: 200,
        body: { route: request.path },
    });

    const server = createServer((req, res) => {
        if (req.method === "GET" && req.url === "/info") {
            res.writeHead(200, { "Content-Type": "application/json" }).end(
                JSON.stringify(testInfo(id)),
            );

            return;
        }

        const chunks: Buffer[] = [];

        req.on("data", (chunk: Buffer) => chunks.push(chunk));
        req.on("end", () => {
            const request: StubRequest = {
                path: req.url ?? "",
                apiKey: req.headers["x-api-key"]?.toString(),
                contentType: req.headers["content-type"],
                body: Buffer.concat(chunks).toString(),
            };

            requests.push(request);

            const reply = handler(request);

            res.writeHead(reply.status, {
                "Content-Type": "application/json",
            }).end(JSON.stringify(reply.body));
        });
    });

    const close = () =>
        new Promise<void>((resolve) => {
            if (!server.listening) {
                resolve();
                return;
            }

            server.closeAllConnections();
            server.close(() => resolve());
        });

    return new Promise((resolve, reject) => {
        server.listen(0, "127.0.0.1", () => {
            const address = server.address();

            if (!address || typeof address === "string") {
                reject(new Error("Stub processor has no TCP address"));
                return;
            }

            resolve({
                url: `http://127.0.0.1:${address.port.toString()}`,
                requests,
                reply: (next) => {
                    handler = next;
                },
                close,
                [Symbol.asyncDispose]: close,
            });
        });
    });
}
```

```ts
import { setCaller } from "@/http/requestContext";
import { anonymousCaller } from "@/registry/snapshot";
import type { IRegistryService } from "@/services/IRegistryService";
import { KeyRequiredError } from "@/types/errors";
import { UnauthorizedError } from "@dpp/server";
import type { RequestHandler } from "express";

/**
 * Identifies the caller. No `X-Api-Key` header means anonymous, unless anonymous access is off; a header with an
 * unknown or revoked key, including an empty one, is rejected rather than treated as anonymous, so a misconfigured
 * client notices at once.
 */
export function createAuthMiddleware(
    registry: Pick<IRegistryService, "authenticate">,
    options: { readonly allowAnonymous: boolean },
): RequestHandler {
    return (req, res, next) => {
        const raw = req.get("x-api-key");

        if (raw === undefined) {
            if (!options.allowAnonymous) {
                res.status(401).json(new KeyRequiredError().toResponse());

                return;
            }

            setCaller(res, anonymousCaller);
            next();

            return;
        }

        const key = registry.authenticate(raw);

        if (!key) {
            res.status(401).json(new UnauthorizedError().toResponse());

            return;
        }

        setCaller(res, { kind: "key", key });
        next();
    };
}
```

```ts
import { getCaller } from "@/http/requestContext";
import { callerName } from "@/registry/snapshot";
import type { Caller } from "@/registry/types";
import type { IUsageStats } from "@/services/IUsageStats";
import { RateLimitedError } from "@/types/errors";
import type { RequestHandler } from "express";
import { ipKeyGenerator, rateLimit } from "express-rate-limit";

/**
 * Per-minute rate limits: each key by its own limit (none if unlimited), anonymous callers by IP. Counters live in
 * memory, which is correct for a single broker process.
 */
export function createRateLimitMiddleware(options: {
    anonymousLimit: number;
    usage: Pick<IUsageStats, "recordRateLimited">;
}): RequestHandler {
    const limitOf = (caller: Caller): number | null =>
        caller.kind === "key"
            ? caller.key.rateLimitPerMinute
            : options.anonymousLimit;

    return rateLimit({
        windowMs: 60_000,
        // Unlimited callers are skipped before this runs; the fallback only satisfies the type.
        limit: (_req, res) =>
            limitOf(getCaller(res)) ?? Number.MAX_SAFE_INTEGER,
        skip: (_req, res) => limitOf(getCaller(res)) === null,
        keyGenerator: (req, res) => {
            const caller = getCaller(res);

            return caller.kind === "key"
                ? `key:${caller.key.id.toString()}`
                : `ip:${ipKeyGenerator(req.ip ?? "")}`;
        },
        standardHeaders: "draft-8",
        legacyHeaders: false,
        handler: (_req, res) => {
            const caller = getCaller(res);

            options.usage.recordRateLimited(callerName(caller));

            if (caller.kind === "key") {
                console.warn(`Rate limit reached by key ${caller.key.name}`);
            }

            res.status(429).json(new RateLimitedError().toResponse());
        },
    });
}
```

```ts
import { findCaller, findVariantName } from "@/http/requestContext";
import { callerName } from "@/registry/snapshot";
import type { IUsageStats } from "@/services/IUsageStats";
import type { RequestHandler } from "express";

/**
 * Records every finished request in the usage statistics, and logs each 5xx response on its own line.
 */
export function createUsageMiddleware(
    usage: Pick<IUsageStats, "record">,
): RequestHandler {
    return (req, res, next) => {
        const started = performance.now();
        // Captured now: routers may rewrite req.url while handling the request.
        const { method, path } = req;

        res.once("finish", () => {
            const caller = findCaller(res);
            const variant = findVariantName(res) ?? null;
            const name = caller ? callerName(caller) : "unauthenticated";

            usage.record({
                variant,
                caller: name,
                status: res.statusCode,
                durationMs: performance.now() - started,
            });

            if (res.statusCode >= 500) {
                console.error(
                    `${method} ${path} answered ${res.statusCode.toString()} (variant ${variant ?? "-"}, caller ${name})`,
                );
            }
        });

        next();
    };
}
```

```ts
import { dependencyTokens } from "@/dependencies/tokens";
import { getCaller, setVariantName } from "@/http/requestContext";
import type { IProxyService } from "@/services/IProxyService";
import type { IRegistryService } from "@/services/IRegistryService";
import { RouteNotFoundError, VariantNotFoundError } from "@/types/errors";
import { BadRequestError, BaseController, Controller, Post } from "@dpp/server";
import { isProcessorRoute } from "@dpp/shared";
import type { Request, Response } from "express";
import { inject } from "tsyringe";

@Controller("/variants")
export class ProxyController extends BaseController {
    constructor(
        @inject(dependencyTokens.registryService)
        private readonly registry: IRegistryService,
        @inject(dependencyTokens.proxyService)
        private readonly proxy: IProxyService,
    ) {
        super();
    }

    /**
     * Forwards `POST /variants/:name/<processor route>` to a processor of the variant. The body was buffered (not
     * parsed) by `express.raw`; the processor validates it.
     */
    @Post("/:name/*route")
    async forward(
        req: Request<{ name: string; route: string[] }>,
        res: Response,
    ): Promise<void> {
        try {
            const { name, route: segments } = req.params;
            const route = `/${segments.join("/")}`;

            if (!isProcessorRoute(route)) {
                throw new RouteNotFoundError();
            }

            const variant = this.registry.resolve(name, getCaller(res));

            if (!variant) {
                throw new VariantNotFoundError(name);
            }

            setVariantName(res, variant.name);
            res.setHeader("X-Variant", variant.name);

            if (!Buffer.isBuffer(req.body)) {
                throw new BadRequestError(
                    "Request body must be JSON, sent with Content-Type: application/json",
                );
            }

            const response = await this.proxy.forward(variant, route, req.body);

            res.status(response.status)
                .type("application/json")
                .send(response.body);
        } catch (e) {
            this.handleError(res, e);
        }
    }
}
```

```ts
/**
 * Lays out rows as aligned columns separated by two spaces.
 */
export function formatTable(
    header: readonly string[],
    rows: readonly (readonly string[])[],
): string[] {
    const lines = [header, ...rows];
    const widths = header.map((_, column) =>
        Math.max(...lines.map((cells) => (cells[column] ?? "").length)),
    );

    return lines.map((cells) =>
        cells
            .map((cell, column) =>
                column === cells.length - 1
                    ? cell
                    : cell.padEnd(widths[column] ?? 0),
            )
            .join("  ")
            .trimEnd(),
    );
}
```

```ts
import { isValidName } from "@/registry/names";
import { parseArgs, type ParseArgsOptionsConfig } from "node:util";
import { CliError } from "./errors";

/**
 * Parses a command's arguments with `util.parseArgs`: unknown options are errors, and positionals are allowed.
 * Argument errors (unknown option, missing value) become {@link CliError}s.
 */
export function parseArguments<const T extends ParseArgsOptionsConfig>(
    args: string[],
    options: T,
) {
    try {
        return parseArgs<{
            args: string[];
            options: T;
            allowPositionals: true;
            strict: true;
        }>({ args, options, allowPositionals: true, strict: true });
    } catch (e) {
        if (
            e instanceof TypeError &&
            "code" in e &&
            typeof e.code === "string" &&
            e.code.startsWith("ERR_PARSE_ARGS")
        ) {
            throw new CliError(e.message);
        }

        throw e;
    }
}

/**
 * Checks that exactly the named positional arguments were given.
 */
export function expectPositionals(
    positionals: string[],
    names: readonly string[],
): string[] {
    if (positionals.length !== names.length) {
        throw new CliError(
            names.length === 0
                ? "Expected no arguments"
                : `Expected ${names.map((name) => `<${name}>`).join(" ")}`,
        );
    }

    return positionals;
}

export function requireValidName(name: string): void {
    if (!isValidName(name)) {
        throw new CliError(
            `Invalid name "${name}": use lowercase letters, digits, and hyphens, not starting with a hyphen`,
        );
    }
}

/**
 * Reads `--limit`/`--unlimited`: a positive whole number, `null` for unlimited, or `undefined` if neither was given.
 */
export function parseLimit(
    limit: string | undefined,
    unlimited: boolean,
): number | null | undefined {
    if (limit !== undefined && unlimited) {
        throw new CliError("Pass only one of --limit or --unlimited");
    }

    if (unlimited) {
        return null;
    }

    if (limit === undefined) {
        return undefined;
    }

    const value = Number(limit);

    if (!Number.isInteger(value) || value < 1) {
        throw new CliError(
            `Invalid limit "${limit}": expected a whole number of requests per minute`,
        );
    }

    return value;
}

/**
 * Reads `--port`/`--url` into an instance base URL without a trailing slash. `--port` means a processor on this
 * machine.
 */
export function instanceUrl(values: { port?: string; url?: string }): string {
    const { port, url } = values;

    if (port !== undefined && url === undefined) {
        const number = Number(port);

        if (!Number.isInteger(number) || number < 1 || number > 65535) {
            throw new CliError(`Invalid port "${port}"`);
        }

        return `http://127.0.0.1:${number.toString()}`;
    }

    if (url !== undefined && port === undefined) {
        let parsed: URL;

        try {
            parsed = new URL(url);
        } catch {
            throw new CliError(`Invalid URL "${url}"`);
        }

        if (parsed.protocol !== "http:" && parsed.protocol !== "https:") {
            throw new CliError(`The URL must use http or https: "${url}"`);
        }

        if (parsed.search || parsed.hash) {
            throw new CliError(
                `The URL must not have a query or fragment: "${url}"`,
            );
        }

        return url.replace(/\/+$/, "");
    }

    throw new CliError("Pass exactly one of --port or --url");
}
```

```ts
function describeProbe(probe: Probe): string {
    switch (probe.state) {
        case "healthy":
            return "healthy";
        case "mismatch":
            return `mismatch (reports "${probe.info.id}")`;
        case "down":
            return `down (${probe.reason})`;
    }
}

function row(
    variant: Variant,
    url: string,
    state: string,
    info?: InfoResponse,
): string[] {
    return [
        variant.name,
        variant.aliases.join(", ") || "-",
        variant.public ? "public" : "private",
        url,
        state,
        info?.mode ?? "-",
        info?.algorithm ?? "-",
        info?.calculatorVersion ?? "-",
    ];
}

 * Checks every instance's `GET /info` directly (not through the running broker) and prints one row per instance.

export const showStatus: Command = async (
    args,
    { repository, processors, healthCheckTimeoutMs, out },
) => {
    const { positionals } = parseArguments(args, {});

    const variants = [...(await repository.loadSnapshot()).variants.values()];

    if (variants.length === 0) {
        out.info("No variants.");

        return;
    }

    const rows = await Promise.all(
        variants.flatMap((variant) =>
            variant.instances.length === 0
                ? [Promise.resolve(row(variant, "-", "no instances"))]
                : variant.instances.map(async (instance) => {
                      const probe = await probeInstance(
                          processors,

                          instance.url,
                          describeProbe(probe),
                          probe.state === "down" ? undefined : probe.info,
                      );
                  }),
        ),
    );

    for (const line of formatTable(
        [
            "VARIANT",
            "ALIASES",
            "ACCESS",
            "INSTANCE",
            "STATE",
            "MODE",
            "ALGORITHM",
            "CALCULATOR",
        ],
```

```ts
    // Released in reverse order on shutdown: server, timers, usage summaries, then database.
    const resources = new AsyncDisposableStack();
    const container = getContainer();

    try {
        const database = resources.use(
            new DatabaseConnection(config.database, schema),
        );

        await database.db.execute(sql`select 1`);
        await database.migrate(
            fileURLToPath(new URL("./drizzle", import.meta.url)),
        );

        registerDependencies(container, { config, db: database.db });

        const registry = container.resolve(dependencyTokens.registryService);
        const health = container.resolve(dependencyTokens.healthMonitor);
        const usage = container.resolve(dependencyTokens.usageStats);

        await registry.load();
        console.log(`Loaded registry: ${registry.summary()}`);

        // Down processors do not stop startup; they become available once a later check succeeds.
        await health.checkAll();

        resources.use(usage.start());
        resources.use(registry.startReloading());
        resources.use(health.start());

        const server = resources.use(new GracefulServer());
        const port = await server.listen(
            createApp(container, server.middleware),
            config.port,
        );

        console.log(`Listening on port ${port.toString()}`);
    } catch (e) {
        await resources.disposeAsync().catch((disposeError: unknown) => {
            console.error(
                "Failed to release resources after a startup failure:",
                disposeError,
            );
        });

        throw e;
    }

    const shutdown = createShutdownHandler({
        resources,
        // In-flight forwards may take up to the processor timeout; let them finish.
        timeoutMs: (config.processor.timeoutSeconds + 5) * 1000,
    });

    process.once("SIGINT", shutdown);
    process.once("SIGTERM", shutdown);
    process.on("SIGHUP", () => {
        const registry = container.resolve(dependencyTokens.registryService);

        void registry.reload().then((reloaded) => {
            if (reloaded) {
                console.log(`Reloaded registry: ${registry.summary()}`);
            }
        });
    });
}

main().catch((e: unknown) => {
    console.error("Startup failed:", e instanceof ConfigError ? e.message : e);
    process.exit(1);
});
```

````markdown
# Broker

The single entry point for clients. Routes calculation requests to processors by variant name or alias, with per-key
access and rate limits. See `docs/superpowers/specs/2026-10-07-broker-design.md`.

## API

| Route                                     | Purpose                                            |
| ----------------------------------------- | -------------------------------------------------- |
| `GET /variants`                           | the variants the caller can use, with their status |
| `GET /variants/:name`                     | one variant; `:name` can be an alias               |
| `POST /variants/:name/difficulty`         | forwarded to the processor's `POST /difficulty`    |
| `POST /variants/:name/performance`        | forwarded to `POST /performance`                   |
| `POST /variants/:name/performance/replay` | forwarded to `POST /performance/replay`            |

Without an `X-Api-Key` header, callers are anonymous: they see public variants only and are limited per IP. To turn
anonymous access off (for example while the beatmap service is near osu!'s rate limit), set `ANON_RATE_LIMIT=0` and
`pm2 restart dpp-broker`; requests without a key then get `401 UNAUTHORIZED`. Request
bodies are the processor's (see `packages/shared`); responses carry an `X-Variant` header naming the variant that
answered.

## Setting up

1. Create the registry database: `CREATE DATABASE dpp_broker;`. Migrations run at startup and before every CLI
   command.
2. Build: `pnpm --filter @dpp/broker build`.
3. Set the same `API_KEY` on every processor's PM2 app, and use it as the broker's `PROCESSOR_API_KEY`.
4. Register processors with the CLI (below), then start the broker.

## Managing the registry

The CLI reads only the database variables. On the server, put them in `apps/broker/.env.production` and run it with
`NODE_ENV=production`, or export them in the shell.

```bash
cd apps/broker
export NODE_ENV=production

# A variant and its processor(s)
pnpm cli variant add droid-live --public --description "Live droid algorithm"
pnpm cli instance add droid-live --port 3101
pnpm cli instance add droid-live --url http://10.0.0.5:3101

# A stable name clients can use, repointed when the live variant changes
pnpm cli alias set live-droid droid-live

# Keys: the key is printed once
pnpm cli key create discord-bot --unlimited --grant flowaim-experiment
pnpm cli key create my-key --unlimited --all-variants
pnpm cli key create some-site --limit 120
pnpm cli key revoke some-site

# Is every processor up, and is each one the variant the registry says?
pnpm cli status
```

Run `pnpm cli` without arguments for every command. The running broker applies changes within
`REGISTRY_RELOAD_INTERVAL_SECONDS`, or immediately after `pm2 sendSignal SIGHUP dpp-broker`.

## Environment variables

| Variable                                          | Default                  | Purpose                                                                        |
| ------------------------------------------------- | ------------------------ | ------------------------------------------------------------------------------ |
| `PORT`                                            | required                 | HTTP port                                                                      |
| `DATABASE_HOST`, `DATABASE_NAME`, `DATABASE_USER` | required                 | the registry database                                                          |
| `DATABASE_PORT`                                   | `5432`                   |                                                                                |
| `DATABASE_PASSWORD`                               | empty                    |                                                                                |
| `PROCESSOR_API_KEY`                               | required, 16+ characters | sent to processors; each processor's `API_KEY`                                 |
| `PROCESSOR_TIMEOUT_SECONDS`                       | `30`                     | longest wait for a processor response                                          |
| `HEALTH_CHECK_INTERVAL_SECONDS`                   | `10`                     | how often every instance's `GET /info` is checked                              |
| `HEALTH_CHECK_TIMEOUT_SECONDS`                    | `3`                      |                                                                                |
| `REGISTRY_RELOAD_INTERVAL_SECONDS`                | `30`                     | how often CLI changes are picked up                                            |
| `ANON_RATE_LIMIT`                                 | `30`                     | requests per minute per IP without a key; `0` requires a key for every request |
| `TRUST_PROXY`                                     | `false`                  | Express `trust proxy`: `true`, a hop count, or addresses/subnets               |
| `USAGE_SUMMARY_INTERVAL_SECONDS`                  | `300`                    | how often usage is logged; `0` turns summaries off                             |

`TRUST_PROXY` must match the deployment. Behind nginx on the same machine, use `loopback`; behind Cloudflare and
nginx, list both. If it is wrong, every anonymous caller shares the proxy's IP and its rate limit.

## Logs

Lines are prefixed `[broker]`. Expect a usage summary per variant and per caller every
`USAGE_SUMMARY_INTERVAL_SECONDS`, one line per 5xx response, one per rate-limited key request, and one whenever an
instance changes state (`healthy`, `down`, or `mismatch`: the processor at that address reports another variant).
Keys and request bodies are never logged.
````
